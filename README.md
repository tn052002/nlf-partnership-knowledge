## Status convention

- **Placeholder** — structure agreed; content not yet drafted.
- **Draft** — usable for review, not yet approved.
- **Approved** — jointly accepted as current policy.
- **Superseded** — retained for history; no longer active.

The source PDFs remain evidence. The manual is the evolving operating truth.
