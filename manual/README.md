# Core Operating Manual

The manual converts partnership strategy into repeatable operations.

Each chapter should eventually contain:

- Purpose and scope
- Principles and non-negotiables
- Roles and decision rights
- Standard process
- Metrics and review rhythm
- Templates and checklists
- Open questions
- Change history

## Editing rule

Do not treat assumptions as policy. Mark unresolved matters as **Open decision**, identify an owner, and link the final decision record when resolved.
